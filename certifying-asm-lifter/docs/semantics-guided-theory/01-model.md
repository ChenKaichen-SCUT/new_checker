# 有限并发生成语言、固定 TSO 语义与观察边界

研究基线：`8142a6bb212e685e1397d68ce8d33e65afe48886`。本文只定义数学对象。
不运行生成器、编译器、后端、SMT 或测试；不赋予任何旧实现新的接受范围。

## 1. 对象与层次

用 `B32={0,…,2^32−1}`，`Bool={false,true}`。对象集合 `Obj` 有限且非空，所有对象均为
有效、对齐、完整的 32 位存储单元；不同对象不重叠，同一对象标识表示精确别名。
不存在未知指针、部分重叠、混合宽度、释放或对象生存期变化。

输入向量 `u` 取非空有限集合 `D⊆B32^k×Bool^b`。D 由第 2 节所列总运算构成的
有限表达式 DAG 谓词给出，不能由目标验证器结果缩小。初始化 `ι:Obj→B32` 可是
u 的总函数，但也必须由同类有限表达式 DAG 表示。每个程序是

`P=(Obj,D,ι,T,CFG,InitLocal,ObsSpec)`，

其中 T 是固定、有限且非空的全部线程实例集合，CFG(t) 是有限无环、单入口、有完整终点的
控制流图。固定线程实例是 DSL 的语法，不是从某次 Q 快照推测的动态出现。
不存在动态创建、循环、递归、间接调用、阻塞、异常、assume、提前错误退出或
中途 assert。所有线程都完成后才解释终端安全观察。需要这些功能必须另立语义
及证明，不把它们转为未声明的运行时假设。

区分四层：

1. 源级抽象命令：读、写、FAA32、局部赋值、分支等。
2. 开放路径解释：给定读响应，产生带值、地址、标签的端点及局部终态。
3. 闭合全局图：选择统一 rf/co，派生 fr，并验证固定 CAT。
4. 终端观察与性质：对全部合法闭合图取指定投影，再量化安全或存在违反。

GNU C、LLVM 和 Dat3M Q 均不参与定义以上四层。未来渲染/导入需要另外检查的
语义桥；此处从 FAA 命令到 R/W 端点只是 DSL 的定义，不是完整 x86 ISA 的证明。

## 2. 类型化语法与合法输入

表达式由字面量、已定义局部值和输入构成，允许 bv32 的模加/减/乘、位运算、
显式按模 32 解释的移位、无符号比较、布尔连接及总的 `ite`。为避免歧义，不包含
除零、有符号溢出、poison、未定义移位或隐式类型转换。每个运算有固定输入输出
类型和全域数学定义。`ite` 的两个表达式须各自定义，不借非活跃分支掩盖无定义值。
输入域、初始局部值、共享初值和性质 φ 均遵守同一有限表达式表示；求值按 DAG
拓扑顺序共享子表达式，不能附加任意可判定但无已知求值成本的外部谓词。

命令：

```
v := e                        // 纯局部、总函数
v := Load32(a)                // a 是 Obj 中的固定对象
Store32(a,e)
v := FAA32(a,e)               // 返回旧值，写回旧值 + e mod 2^32
Fence                         // full fence，独立扩展；未使用时集合为空
if g then goto n1 else goto n2
goto n
return locals
```

可用 SSA/phi 表示合流，但 phi 必须按实际前驱选择；或使用普通局部环境与明确的
赋值规则。每条路径使用的值必须已经初始化/定义。一个仅在某分支赋值的变量不能
无条件在合流后使用，除非另一路径也赋值或合流规则提供合法定义。静态路径位置、
执行的活跃事件及最终观察是不同概念。

良构要求：CFG 边闭合、可判定无环；每个节点从入口结构可达并可到达返回
（不要求所有结构路径都语义可行）；非终点的转移精确为一条无条件边或互补两边；
每终点满足 ObsSpec 的类型和定义条件；每个源操作被消费；对象/变量命名有限。
可按所有有限路径进行定义分析，不需要依赖不完备的别名或路径启发式。

## 3. 开放执行与 FAA 的完整端点

给定输入 u 和某线程读响应序列，按 CFG 计算纯表达式及分支。Load 产生一个 R；
Store 产生一个 W；FAA 在同一个命令处产生相邻的 R、W，二者标记 A，加入唯一
`rmw(r,w)`，其中 `val(w)=val(r)+eval(e)`，局部结果为 `val(r)`。FAA 的参数 e
在该操作前求值，不读取尚未定义的 r。Fence 产生一个 F 节点。纯操作不产生共享
访存，但其数据与控制依赖不能从路径解释中删除。

读响应为完整 B32 值域上的任意值。其可达性在闭合图中判断；不能在开放阶段
根据目标求解结果或“似乎只会读到小数”裁剪。仅实际走过路径上的读需要值；
非活跃事件没有伪造的执行值、rf 或 co 边。

一条开放路径结果为 `(π,Eπ,labπ,poπ,rmwπ,σend)`。`poπ` 是该线程所有活跃
端点及 Fence 的严格全序。路径记录局部定义和每个分支条件的实际取值。

## 4. 固定全局执行图

每个对象 a 有唯一初始写 `I_a`，值为 `ι(u)(a)`，其线程标识不同于全部实际线程；
初始写之间不建立 po。对所有线程的一个开放执行族取不交并，得到

`G=(u,E,lab,po,rf,co,fr,rmw,End)`。

这里 E 包含初始写、实际 R/W、Fence。令 M=R∪W；CAT 的共享关系限制到 M。

* rf 从同对象 W 指向 R，每个 R 恰有一个供值写，值一致。没有隐含外部写。
* co 对各对象所有活跃 W（包括初始写）是严格全序，初始写最小；不同对象无 co。
* `fr=rf⁻¹;co`，不是可自由选择的输入。
* `rfe/fre/coe` 是对应关系在不同线程端点上的限制。
* `po-loc` 是 po 在同址内存端点上的限制。
* `mfence=(po;[F];po)∩(M×M)`。
* rmw 和 A 由完整 FAA 解释决定，不能作为候选匹配器的自由变量。

TSO 约束为冻结仓库中的三条约束：

```
U = po-loc ∪ rf ∪ co ∪ fr
K = (po ∩ (R×M ∪ W×W)) ∪ mfence
  ∪ (po ∩ W×R ∩ (M×A ∪ A×M))
Tso = K ∪ co ∪ fr ∪ rfe
acyclic(U)
empty(rmw ∩ (fre;coe))
acyclic(Tso)
```

模型文件身份沿用 [固定模型记录](../../backend/dat3m/pins.json)：
`tso.cat` SHA256 `8561d85057c449c0828b888c61e3cfeda8b73750474353eee1dd3f0383b192ac`；
`x86fences.cat` SHA256 `b7d347726619c89e336bb19fd0ed5284d0b2fb893f06c957644ab769de691766`。
这是固定公理模型的数学语义，不是对所有称作 TSO 的模型的等价主张。

记 `Exec_T(P,u)` 为满足路径解释、对象/值约束及以上统一全局约束的全部完整图。
各线程分别找到局部合法图不是加入此集合的充分条件。

## 5. 观察、等价及非空性

`last_G(a)` 是 a 的 co 最大写的值。它是模型中全部线程完成、最终写均生效后的
观察函数，不是在 worker 中偷偷加入一个可重排序的普通 C 读。ObsSpec 显式选择
哪些对象终值和哪些终端局部值被观察；所有比较始终包含输入 u 的身份。静态源
位点编号不属于该观察；若要额外观察来源身份，03 的复制/合并定理必须重新审查。

`Obs_P(G)=(u,投影(last_G,End))`，`B_T(P)={Obs_P(G):u∈D,G∈Exec_T(P,u)}`。

本文的安全指终端谓词 `φ(u,obs)` 对 B_T(P) 恒真。它不保证线程库调用成功、
中途错误不发生或无限执行安全。观察接口不相同的两个程序不能直接比较集合；
须先明确一个类型保持的观察转换，且不能悄悄删掉活跃 FAA 返回值。

更强的事件历史等价要求两边活跃图存在保值/类型/对象/线程及 po/rf/co/fr/rmw/A/F
的重命名，并保持指定局部输出。证明这一级可以推出指定观察等价；反向不成立。

**非空引理。** 对每个良构 P、每个 u∈D，Exec_T(P,u) 非空。

证明：选任意线程全序，按该序逐个执行完整线程；使用当前共享值回答每个读，
Store 立即更新共享值，FAA 作为不可分割的一步读/更新，Fence 无需额外更新。
所有表达式总定义且 CFG 无环，故有限到达终点。初始写最先，每次写按这条执行
轨迹排入各对象 co，rf 取最近同址写。所有 po、rf、co、fr 及 mfence 边都严格
沿该总执行的端点次序前进，U/Tso 无环；FAA 的 R/W 间无别的写，禁止关系为空。
故构造的全图合法。这里构造一条 SC 执行只证明非空，不把所有 TSO 执行限制成 SC。□

## 2. 交叉审阅后已修正的定义精度

1. **总可判定不等于多项式求值。** 最初若允许任意总输入谓词/初始化函数，
   02 的 poly(S) 求值上界不成立。现 01/02/05 统一要求输入域、初值、局部运算
   和性质为所列总算子的有限表达式 DAG；界内按 DAG 求值。任意外部总算法不在域中。
2. **权重可计算性。** 04 明确为有限编码非负有理数，排除不可计算实数比较；
   运算次数与数值位复杂度分开，不把前者冒称后者。
3. **R1 的范围。** 由关系模式查询得到的池只保证 F_h 覆盖，不自动涵盖可选
   静态互斥或变换类别；且最大覆盖近似只相对实际候选池。
4. **证书集合绑定。** 05 新增全部合法叶子观察并集与声明 B 的双向相等检查，
   同时显式检查每个见证输入∈D。否则合法见证列表仍可能遗漏真正坏观察。
5. **观察及记录成本。** 输入身份纳入观察；终端局部数界包含布尔值；证书成本
   计入纯计算/路径 S 和输入 k，而非只计内存端点 N。
6. **静态编号与 Fence。** T3 不保持被合并的静态位点身份观察；01/03 已明确。
   字面 mfence 与内存投影的关系由 02 引理证明，不用省略符号掩盖差异。

这些修正收紧了命题，没有改动历史定理或增加外部编译正确性假设。

# 性质预期、差异方向及未来独立核验证书

本文件只定义证据协议和逻辑判据，不实现检查器，不调用工具。语义与输入域固定于
[01](01-model.md)，精确图集合算法见 [02](02-independent-decision.md)。

## 1. 预期结果是集合命题，不是一次执行的归纳

记 B(P) 为全部输入下的合法终端观察集合，元素包含输入身份。令 φ 是该有限观察
类型上由 01 总运算的有限表达式 DAG 表示的布尔谓词。定义：

```
SAFE_DSL(P,φ)   ⇔ ∀o∈B(P). φ(o)
UNSAFE_DSL(P,φ) ⇔ ∃o∈B(P). ¬φ(o)
EQ_OBS(P,Q)    ⇔ B(P)=B(Q)                  // 相同输入和观察接口
INCL_OBS(P,Q)  ⇔ B(P)⊆B(Q)
```

这里 SAFE_DSL 仅是有限抽象语言的终端性质真值，不是原项目的 L4 或源 C 安全
证书。对象、输入、线程集合和观察投影必须属于命题，不能事后改掉以使结果一致。

**定理 O1。** 算法 E 给出精确集合 B 后，检查全部元素均满足 φ，当且仅当
SAFE_DSL；找到一个不满足的元素和其合法全图，当且仅当 UNSAFE_DSL。

证明：E 的可靠性保证被选见证确有合法执行；E 的完备性保证真实合法观察都在 B。
分别代入全称和存在量词即得两方向。若求解中断，只有已核验正见证仍可保留；
不能由已列元素均满足 φ 得出全称命题。□

### 1.1 自动产生至少一项安全及不安全性质

给每个 b∈B 写出有限等值合取 `eq_b(o)`，其分量包括输入。令

`φ_safe(o)=∨_{b∈B} eq_b(o)`。

按 O1，此性质恒成立。B 不是由目标输出构造；表达式可能很长，其规模与观察数
及观察位数成正比。若结果恰为整个观察类型，这个性质可能逻辑恒真，仍有真值，
但不应声称具有高缺陷揭示能力。

由 01 非空引理，任选 b∈B，令 `φ_bad(o)=¬eq_b(o)`。与 b 对应的合法图违反它，
因此 UNSAFE_DSL。另一选择是从有限谓词族中筛选同时具有满足/违反图的谓词；
没有这种谓词的程序如实报告，不捏造输入非确定性。

观察投影 π 可以预先固定为部分终值。此时应先计算 `π(B)`，在该投影域内形成
性质并保留原始执行见证；不得把 π(B) 相同写成完整 B 相同。只保留 final(x) 会
隐藏 FAA 返回错误或中间共享写，是强度变化，不是语义错误已消失。

## 2. 关系性质与单个执行对的陷阱

**定理 O2。** 同一输入/观察接口下，精确算出两侧 B 后，集合相等判定恰等价于
EQ_OBS。若给出 b∈B(P) 和 b∉B(Q) 的完整证据，则可可靠断言指定方向的行为差异。

证明：正面是集合外延性；负面由集合差的定义。存在一个 P 执行与一个 Q 执行
观察不同，仅给出 `∃p∈B(P),q∈B(Q).p≠q`；它不等于集合差非空。例如两侧均
为 {0,1}，选择 0 与 1 就不同，但集合完全相同。□

不必总是枚举两侧：03 的规则证书给双向全图对应，已经足以推出 EQ_OBS。
规则不适用时，不可从“未能证明”等价推出不等价；保留未知，或使用完整判定。

**方向。** 编译精化常考察 `B(target)⊆B(source)`，而为验证安全不能漏掉源错误，
需要 `Err(source)⊆Err(target)`；`B(source)⊆B(target)` 是其充分条件。二者不能
互换。错误报警的认定还取决于目标工具承诺精确判定，还是允许保守 MAY-ERROR。

## 3. 开放赋值的可达性

一个开放证据 θ 必须列出输入约束、潜在读位点身份、该位点须活跃、读值/局部值
等式及相关路径条件。定义

`Reach(P,θ)={G∈⋃_{u∈D}Exec_T(P,u): G满足θ}`。

* 合法全图见证足以证明 REACHABLE_DSL。
* 精确判定给 Reach(P,θ)=∅，才足以证明 UNREACHABLE_OPEN_ASSIGNMENT。
* 超时、缺少路径、只检查某些 rf/co、未排除其他输入：UNKNOWN。

**定理 O3。** 完整图算法附加 θ 的过滤后，上述前两项分别可靠且完备。

证明：θ 是固定有限图上的可判定谓词。对 Exec_T(P) 的精确枚举逐个过滤，恰得
集合交，没有改变基础语义或向目标借用输入域。若读位点被 θ 声明活跃，则没有
该位点的图不满足 θ；不能以“未执行所以值任意”承认无效见证。□

数学例：x=0，两个线程各 FAA32(x,1)。02 的 co 直接前驱引理给出读值为 0 和 1，
顺序依 co 决定；首个指定位点读 7 的开放赋值在完整图中不可达。该结论只否定
这个 θ 的全部扩展，不否定其他开放差异，也不说明整个程序正确。

## 4. 证书的逻辑结构

未来实现可使用下列记录，但本轮没有创建可执行格式或核验器。

| 记录 | 必要字段 | 独立核验义务 |
|---|---|---|
| ModelManifest | 完整 DSL 编码、类型、CFG/终点、D、初始化、线程全集、对象、观察、CAT 版本 | 重新检查良构、总性、无环、对象宽度及模型公式身份；散列只防混用 |
| ExecutionWitness | 输入、每线程路径和逐步局部值、全部活跃端点、标签、rf、co、rmw、终态 | 显式检查输入∈D；从程序重新解释路径；端点全集相等；rf 唯一且值一致；co 全序/初始化；fr 必须重算；CAT 无环及原子性 |
| ExactBehaviorCertificate | 完整覆盖树或精确有限公式、全部观察及合法见证、剩余空间空的证明 | 覆盖证明不能由候选枚举器的“complete=true”标记替代 |
| PropertyCertificate | φ 的总类型化表达式、观察接口、SAFE/UNSAFE、关联覆盖或违反图 | 重新求值 φ；全称结论需完备性，存在结论需合法见证 |
| TransformCertificate | 两侧程序、规则名、完整区域、定义/使用、活跃输出、全称等式证据 | 按 03 检查全部侧条件和双向运输；不信人工给定静态映射 |
| RelationCertificate | 同一输入域/观察、方向、相等/包含或差异 b | 相等需双包含；差异需一侧存在图和另一侧完整排除 |
| FeatureCertificate | 模式、全图及嵌入；排除型模式的覆盖证据 | 检查完整图后再取诱导模式；小图可行性不能代替全图扩展 |
| SelectionCertificate | 固定候选池/预算/权重、精确特征集合、每步边际收益和选择 | 重算集合操作；最优近似主张必须满足 04 的完整池/同成本前提 |

### 4.1 一个完全有限、无需信任求解器口头状态的完整性证据

使用 02 的有限决策顺序形成覆盖树：输入分量、路径/读响应、rf 候选、对象写入
排列均有明确有限的分支集合。每个内部节点的子节点必须恰好覆盖该位置的全部
允许选择且无重复；叶子为合法图，或包含可直接核验的具体拒绝理由（路径条件
矛盾、供值不等、非法 rf/co、禁止原子中间写或显式环）。

树高有限，但可以巨大。核验器由根归纳：内部全分支覆盖和各子树完整，推出
该前缀全部扩展被覆盖；叶子直接判断。核验器还必须重算**全部合法叶子**的观察
并集，与证书声称的 B 做双向集合相等检查；只检查所列见证合法会允许漏报观察。
于是根的完整性与每个接受图的可靠性共同给出精确行为集合。不要求每个不同图都留下不同终态；可以汇总观察，但
用于语义特征的图证据仍要保留。子树压缩只有在明确验证其状态/剩余选择相等
时才可共享，不能用哈希碰撞或看似相同的终态作为替代证明。

另一方案是 02 的精确有限公式及观察阻断，附可独立检查的 UNSAT 证明（包括
位向量位爆破对应和命题证明）。单纯保存 SMT 文本和“UNSAT”日志仍依赖求解器
可信性，不满足“独立证明对象”这一更强要求。可选择有限覆盖树作为理论上
完整的参考路径，无需预先假设未来证明格式或 SMT 前端已经验证。

### 4.2 核验器可靠性定理（规范层面）

若一个按上述规则定义的数学核验器接受证书，则证书声称的 DSL 结论成立。

证明：ModelManifest 固定 01 的语义；ExecutionWitness 的逐项检查正是合法图
定义，因此执行存在。覆盖树的高度归纳给出所有合法选择均被覆盖，再由 02 的
判定可靠性/完备性得到精确图/观察集合。Property/Relation 分别应用 O1/O2/O3；
Transform 应用 03 已证明的规则；Feature/Selection 应用 04 的 S1–S3。证书
之间必须引用同一程序、输入、模型和观察，否则前提不成立。□

这是未来核验规则的数学充分性，不是对某段 Python、解析库、文件系统或求解器
实现的证明。旧八项 Γ 不被改写；未来新增实现的可信表面须独立列出。

## 5. 未来实际工具结果的分级，当前不执行

| 可证明的状态 | 足够证据 | 不能升级为 |
|---|---|---|
| DSL_EXPECTED_SAFE / DSL_EXPECTED_UNSAFE | 完整独立 oracle / 合法违反图 | 真实 C 的 L4 证书 |
| OPEN_DIFFERENCE | 开放关系义务失败且所有替代匹配已排除 | 完整并发执行差异 |
| REACHABLE_DSL | 完整图、路径、初始化及统一关系有效 | 某真实软件进程必会发生 |
| UNREACHABLE_OPEN_ASSIGNMENT | 完整源图空间排除 θ | 所有差异不可达 |
| OBSERVATION_DIFFERENCE_DSL | 一侧合法图与另一侧完整排除 | 被测验证器缺陷 |
| UNSUPPORTED / INVALID_INPUT | 工具域不符 / DSL 或桥接前提不成立 | false SAFE、真实漏洞 |
| TOOL_RESULT_MISMATCH_SUSPECTED | 预期与实际结果不同，但链路尚有缺口 | 已确认错误结论 |
| CONFIRMED_RESULT_ERROR（未来） | 有效生成/渲染、实际输入与属性、完整工具承诺、独立真值、实际同次结果及必要反例/排除 | 任意程序或工具版本均不可靠 |

确认实际错误的最后一行目前没有实现保证。本阶段不会用新理论反向重解释历史
实验，也不会实施软件缺陷搜索。正确 oracle 是将来测试的基础，不是充分的全部
实验协议；编译选项差异、不支持语义、捕获缺字段、错误查询或宿主桥接缺口都
可能造成表面不一致，需要单独判定。

## 6. 证据的成本与不可删前提

存在见证含 O(N²) 个关系位、O(wN) 个事件数值位，以及纯计算/路径规模 S 和总
输入位数 k 对应的记录；若逐步保存全部局部环境，朴素记录可达 O(wS²+k)。具体
图核验可用 O(N³) 的直接关系检查上界，加按表达式 DAG 和路径求值的多项式成本。
不能用内存端点数 N 限定任意多的纯计算记录。完整图/观察集合与覆盖树
可能指数乃至随 32 位响应枚举而极大；不存在从小 SAT 见证直接得到廉价 SAFE
证书的推论。若独立核验成本过高，正确动作是标记资源限制或选择更小的公开域，
不能删除未探索线程、路径、写或输入值以制造确定预期。

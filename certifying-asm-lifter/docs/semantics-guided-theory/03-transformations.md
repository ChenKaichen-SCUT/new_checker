# 语义保持变换、双向执行图证明与边界反例

本文件是冻结提交 `8142a6bb212e685e1397d68ce8d33e65afe48886` 上新增的纯理论研究。没有运行编译器、后端、求解器或测试生成器。以下命题只涉及本目录定义的有限语言；它们不是 Clang 实现正确性证明，不扩大 L1–L4、ACTC、guarded 或原八项 Γ 的结论。

## 1. 比较对象、观察与证明强度

采用 [01-model.md](01-model.md) 中的有限模型：完整线程向量预先给定，各线程 CFG 无环；共享对象已初始化、有效且互异；计算是总的定型表达式；每个使用点的局部值在该路径上已定义；所有线程完成后才取观察。没有中途 `assert`、`assume`、异常退出或失败前缀。本文件的 `FAA(x,d)` 均为 32 位模加法，返回旧值；抽象为同线程、相邻的读取端点 `r` 与写入端点 `w`，`rmw(r,w)` 成立，两个端点都保留模型规定的原子标签 A，且 `value(w)=value(r)+d mod 2^32`。

一个完整执行记为 `G=(i,E,lab,po,rf,co,rmw,π,ν)`。`i` 是合法输入，`π` 是每条线程的已选路径，`ν` 给出该路径的局部求值。`fr=rf⁻¹;co`，而不是独立挑选的关系。初始化节点及每个对象的初始值也属于 G。`po` 是同线程实际事件的严格先后关系；路径上未发生的静态节点不属于 E。任何“在别的分支也存在一个静态 FAA”的事实都不能令它在本次执行中发生。

终端观察 `Obs(G)` 包含输入 i、声明可观察的终端局部值及每个被观察对象的 co 最大写入值。输入参与观察，禁止用另一个输入的目标执行匹配本输入的源执行。证明允许明确的局部变量 α 重命名；不把编译来源编号或静态 AST 节点编号作为运行时观察。如果希望观察这些编号，本文的静态复制/合并定理不适用。

本文区分三种结论：

1. **完整执行图对应**：存在标签与关系保持的双射，覆盖本次执行的全部事件以及全局 rf/co/fr，不只覆盖局部片段。
2. **指定终端观察集合相等**：对每个固定输入，两个程序的全部合法执行产生相同的观察集合。
3. **某个特定终端量相等**：例如两者最终 x 都为 2；这不蕴含前两项。

本文主要正面定理证明第 1 项，并因此得到第 2 项。反例说明仅有第 3 项为何不足。后续只基于指定投影选择测试时，应同时记录投影；不允许把较弱观察下的相等称为完整并发行为相等。

## 2. 全局图运输引理

**引理 T0（保持关系的重命名）。** 给定合法完整执行 G 和双射 `h:E→E′`。若 h 固定初始化节点和对象身份，保持线程身份、事件种类、访问位宽、地址、读写值、A/Fence 标签，并满足：

```
po′   = h(po)       rf′ = h(rf)
co′   = h(co)       rmw′ = h(rmw),
```

且目标路径的局部语义与这些读写值一致，那么运输后的完整图 G′ 满足同一固定 TSO CAT。这里 `h(R)={(h(a),h(b)) | (a,b)∈R}`。

**证明。** 双射保持集合并交、关系逆、合成、限制及关系闭包。因此：

* co 的同对象严格全序、初始化最小性、rf 的逐读取唯一性及类型/值一致性全部保持。
* `fr′=rf′⁻¹;co′=h(rf⁻¹;co)=h(fr)`；内部/外部关系限制由线程身份保持，故 `rfe/fre/coe` 也分别被运输。
* 地址不变给出 `po-loc′=h(po-loc)`；`rmw′ ∩ (fre′;coe′)=h(rmw ∩ (fre;coe))=∅`。
* 固定 CAT 的字面 `mfence⁺=po;[F];po` 由 Fence 标签保持；采用 01 的 M×M 投影后仍被运输，字面/投影无环判定等价见 02 引理 2。`implied=po∩(W×R)∩((M×A)∪(A×M))` 由事件种类、A 和 po 保持；所以 `po-tso`、`com-tso`、`ghb-tso` 全部被运输。
* 一个有向关系有环，当且仅当经双射运输后有环：将环逐节点应用 h 得到目标环，反方向应用 h⁻¹。因此 `po-loc∪co∪rf∪fr` 和 `ghb-tso` 的无环性都保持。

最后一项“目标局部语义一致”不是由 CAT 自动提供的，必须由每个变换单独证明。给定它，所有程序求值与内存模型条件均满足。证毕。

此引理属于关系同构的标准推论。它不构造编译来源对应，不证明任何工具导出的图完整，也不允许按片段分别选择互不相容的 rf/co。以下构造从一个完整 G 一次性运输所有关系。

## 3. 变量重命名与总纯表达式改写

### 3.1 局部 α 重命名

**规则 T-ALPHA。** 对一个线程内的局部绑定使用无捕获双射 ρ；同时更改全部定义、使用、phi 前驱值和声明的终端观察名称。共享对象、输入接口及事件操作不变。若输入变量也改名，则输入估值必须按同一双射运输，不能比较不同输入。

**定理 T1。** T-ALPHA 保持完整执行图及指定观察集合。

**证明。** 按每条无环路径的语句顺序归纳。常量不变；变量查找满足 `ν′(ρ(v))=ν(v)`；每个总算子的操作数相等，所以表达式值相等；分支选择相同；phi 选择同一个实际前驱的对应值；Load/FAA 接收相同开放读值时返回及写入值相等。因而活跃事件、标签与顺序完全相同，可以取 h 为事件身份映射。外部线程、rf/co/fr 和全部模型关系不变；观察依照声明的 ρ 对应。逆向使用 ρ⁻¹。证毕。

### 3.2 同输入、同类型的表达式等式

**规则 T-PURE。** 在任意纯表达式位置把 e 替换为 e′，要求二者类型相同、自由变量在该使用点每条可达路径上都已定义，且在**全部**该类型估值上有 `⟦e⟧σ=⟦e′⟧σ`。二者都是总函数，无访存、同步、I/O、隐式异常、浮点环境或未定义行为。表达式所处位置可以是分支条件、FAA 增量、Store 值或终端观察。

**定理 T2。** T-PURE 保持完整执行图及指定观察集合。

**证明。** 固定输入和源合法图，沿各线程路径归纳。在未改写点语义相同；在改写点，归纳假设给出相同局部估值，全称等式给出相同结果。因此不会改变分支选择、访问对象、访问次数、FAA 写值或终端值。图身份映射满足 T0；反向对等式使用对称性。证毕。

例如 `bv32(x+0)=x` 和 `bv32(x+(y+z))=bv32((x+y)+z)` 由模加法群律成立。没有声明为总运算的除零、C 有符号溢出、越界移位不能借用本规则。把“某一次 SMT 模型取值下相等”代替全称等式，会直接破坏证明的归纳步骤。

## 4. 非平凡规则：互斥 FAA 菱形的复制与合并

### 4.1 精确的适用条件

考虑同一线程中一个单入口、单出口的完整控制菱形。进入时局部状态为 σ：

```
源 S：                             目标 T：
if g(σ) then                        d := ite(g(σ), eT(σ), eF(σ));
    rT := FAA32(x, eT(σ));           r := FAA32(x, d);
else
    rF := FAA32(x, eF(σ));
r := phi(rT from T, rF from F);
```

规则 T-FAA-DIAMOND 要求：

* g 是总布尔表达式，eT/eF 是总 bv32 表达式；它们只读取**进入菱形之前**已定义的局部值和输入。此前读入的共享值可以成为这些局部值；规则没有假定这些值为常量，也没有假定它们与其他线程独立。
* 两分支互斥且穷尽，任何进入菱形的完整执行恰好选一条分支。两条分支各有且仅有一次 FAA32，地址都是同一个有效对象 x，原子标签、位宽、模运算及旧值返回语义一致。
* 分支除为表达式求值服务的总纯计算外，没有其他 Load/Store/FAA/Fence、线程动作、隐式调用、提前终止或观察动作。没有路径从中途进入/离开菱形，没有循环。
* 两个 `rT/rF` 仅通过正确前驱上的 phi 导出为 r；其它活跃局部值保持原值。分支临时量不被外部上下文观察，也不被绕过 phi 的使用点读取。若需要导出额外值，必须先为完整活跃值向量逐项证明等式，不能默认它们不存在。
* 新增 d 是新鲜局部绑定，不捕获任何原定义或使用；r 与源出口绑定对应。删去的分支局部名称均不在观察接口内。
* 合并后 d 的求值无额外共享作用。无论 `ite` 的实现是否先求两个纯表达式，二者均已定义且总，因此不会制造异常或副作用。
* 上下文 C 保持不变；C 可以有其他线程、访问 x 或其他对象、跨对象值依赖、后续以 r 为条件的分支和多次同类调用，只要整个程序仍在本有限模型中。允许的观察不包含“源中选中了哪个静态 FAA 编号”；g 或 r 的终端值当然可以被观察。

该变换改变潜在静态表示：源有两个 FAA 位点、四个潜在读写端点；目标有一个 FAA 位点、两个潜在端点。每个**实际执行**仍恰好发生一对 FAA 端点。它不允许把两个实际发生的 FAA 合成一个 FAA。

### 4.2 双向全局执行图构造

**定理 T3。** 对满足以上前提的任意上下文 C 和固定合法输入 i：

```
{Obs(G) | G∈ExecTSO(C[S],i)}
  = {Obs(H) | H∈ExecTSO(C[T],i)}.
```

更强地，两个集合的每个执行都具有一个完整、标签与关系保持的事件图对应，且上下文事件身份不变。

**源到目标证明。** 任取源合法完整图 G。设该线程实际进入菱形前状态为 σ，`b=g(σ)`，实际 FAA 的读取、写入端点为 r_b、w_b，读值为 v。令目标选择 `d=ite(b,eT(σ),eF(σ))`，所以 `d=e_b(σ)`。目标 FAA 取同一读值 v，写值为 `v+d mod 2^32`，等于源写值；返回值仍为 v。源 phi 从实际前驱导出 v，目标 r 也为 v。

构造 h：上下文、其他线程与初始化事件全部取身份；仅将实际 r_b、w_b 分别映至目标 FAA 的 r、w。未选分支的静态端点不在 G 中，不需要也不允许为它们伪造事件。目标在原 FAA 占据的边界处执行这对端点，菱形内没有其他事件，因此 h 保持全线程事件次序，特别是与菱形前后事件、其他 FAA、Fence 的次序。

目标其他线程沿原路径取同一局部值；当前线程到达菱形的状态相同，离开时所有活跃值相同。继续沿后续路径归纳，每个控制条件和每个输出值相同；后续访存使用与源相同的读响应，因此包括数据依赖和条件性访问在内的全部事件标签相同。依次设置 `rf′=h(rf)`、`co′=h(co)`、`rmw′=h(rmw)`，不能局部重新选择其中任何一个关系。T0 给出全局 TSO 合法性。co 的最大元与最终局部值被保持，故观察相等。

**目标到源证明。** 任取目标合法完整图 H。目标到达合并点前局部状态为 σ。由总且确定的 g 得到唯一 `b=g(σ)`，在源选择相应分支。复制目标 FAA 的读值 v 及写值到源该分支，另一分支不执行。因为 `ite` 的定义，增量相等；源 phi 从 b 前驱读出 v。将目标实际 FAA 两端点映到源选中分支的两端点，所有上下文事件保持身份。此前和此后的局部归纳、全部关系运输与 T0 的论证完全适用。所得源图合法且观察相等。两方向都对任意固定输入和任意合法完整图成立；没有假定程序安全。证毕。

### 4.3 证明中的量词与实际能力

这里证明的是 `∀i ∀G ∃h_G` 及反方向，而不是要求一份静态一一映射同时覆盖两个互斥分支。g 由先前读取决定时，不同合法执行可能选择不同 h_G；这些映射由规则、实际路径和前驱确定，不依赖目标验证器的结果。允许程序有任意有限多个符合条件的菱形：每次使用 T3 得到程序级行为集合相等，有限次等式传递得到组合结果。

这是一个有实质语义前提但标准的控制菱形变换证明。新研究可以利用它产生静态结构不同而预期相同的测试对；本文不把它称为新的编译优化定理或新的通用对应合成算法。把它翻译为 GNU C/LLVM 之前，还必须证明对应语言桥接或独立核验每个实际编译对象；本阶段没有完成该工作。

## 5. 受限重排：纯计算可交换，共享事件不按地址自动交换

**规则 T-PURE-SWAP。** 相邻的总纯赋值 `a:=e; b:=f` 中，a≠b，a 不在 f 的自由变量内，b 不在 e 的自由变量内，所有其余自由变量在入口已定义；其间无观察、共享事件或控制转移。交换两条赋值，同时遵守无捕获命名。

**定理 T4。** T-PURE-SWAP 保持完整执行图及指定观察集合。

**证明。** 入口 σ 下，正序得到 `σ[a↦⟦e⟧σ,b↦⟦f⟧σ]`；反序得到同一映射，因为相互自由变量限制使任一求值不读取另一赋值刚写的新值。中间没有共享事件，所以前后事件序列不变。将相同出口状态代入不变上下文，按路径归纳得到相同图，T0 适用。反向条件相同。证毕。

这是一条局部依赖规则，不是仅按语法随机打乱语句。若 `b:=a`，交换通常改变 b；即使最终 b 不被观察，也不能省略其对后续地址、值或 guard 的依赖检查。

本阶段不提出“不同地址的共享访问就可交换”的规则。TSO 的跨线程关系使地址不同仍不足以保证可交换；下一节给出完整反例。若将来只针对某个封闭程序和观察证明一个特定共享重排，需要以完整合法行为集合证明，而不能从 T4 外推。

## 6. 小型数学反例与失败原因

以下均为同一固定 TSO 语义中的数学构造；没有运行程序或向真实工具注入故障。初值默认为 0，数值都是 bv32 中的小整数，故不涉及溢出争议。它们去除了与被攻击条件无关的结构；本文不声称每例在所有可能语言编码下都具有经过下界证明的全局最小节点数。

### X1：不同对象上的两个 Store 不能任意交换

```
P 的线程 0：W(x,1); W(y,1)     线程 1：a=R(y); b=R(x)
P′的线程 0：W(y,1); W(x,1)    线程 1：a=R(y); b=R(x)
观察包括 (a,b)，x≠y。
```

在 P 中假定 a=1、b=0。全局关系必有 `Wy rf→ Ry`、`Rx fr→ Wx`；TSO 有 `Wx po-tso→ Wy`（W→W）及 `Ry po-tso→ Rx`（R→R）。于是 `Wx→Wy→Ry→Rx→Wx` 是 ghb 环，故该观察不合法。

P′ 有合法顺序 `Wy; Ry; Rx; Wx`，读值正是 (1,0)。co 为每对象初始化在前、唯一写在后，rf 取 Wy→Ry 与 Ix→Rx，fr 为 Rx→Wx；po-loc 与 ghb 都沿该顺序无环，且没有 rmw。两个程序最终 x=y=1 相同，但终端读取结果集合不同。这同时否定“最终共享值相等即可”和“对象互异即可重排”。

### X2：两个实际 FAA 合成一个 FAA 会删除可见中间写

```
P： 线程 0：r=FAA(x,1); s=FAA(x,1)    线程 1：v=R(x)
P′：线程 0：r=FAA(x,2); s=r+1        线程 1：v=R(x)
```

P 中合法顺序为第一 FAA、线程 1 的读取、第二 FAA，得到 v=1，最终 x=2。每个 FAA 对的读写相邻且不被任何写插入，rf/co 满足 RMW 原子性。P′ 只有初始写 0 和唯一 FAA 写 2；rf 完整性要求 v∈{0,2}，不可能为 1。即使 P′修复了两个线程 0 返回值的算术结果，仍不能恢复已经删掉的共享中间写。T3 合并的是互斥静态位点，而不是这两个共同活跃的 FAA。

### X3：保持写值而丢失旧值返回仍不等价

一个线程执行 `r=FAA(x,1)`，初始 x=0，观察包括 r。正确语义得到 r=0、final(x)=1；若返回新值则 r=1、final(x)=1。此例只有一次 FAA，已经足以否定“内存最后相同即可忽略返回值”。后续以 r 作 guard 或另一次 FAA 的增量时，差异还会传播到访问次数或共享值。

### X4：没有穷尽的一次执行条件，不能删除 guard

源：`if b then FAA(x,1) else skip`；错误变换：`FAA(x,1)`。合法输入 b=false 时，源没有 FAA，目标有一对 FAA，最终 x 分别为 0 和 1。观察包含 b，不能用源输入 true 的执行替代 false 的执行。该例违反 T3 的“两分支各且仅一次 FAA”，因此不构成 T3 反例，却阻止把它推广到任意条件事件。

若两分支都有 FAA、但把 `ite(g,eT,eF)` 的两个分量颠倒，令 eT=1、eF=2、g=false，即得源 x=2、目标 x=1。互斥本身不证明 guard 与操作数的绑定正确。

### X5：删除一个 Fence 能放入新的 TSO 结果

```
P 的线程 0：W(x,1); FENCE; a=R(y)
P 的线程 1：W(y,1); FENCE; b=R(x)
```

假设 a=b=0，则 `Ry fr→ Wy`、`Rx fr→ Wx`。两道屏障分别给出 `Wx mfence→ Ry` 和 `Wy mfence→ Rx`，形成 `Wx→Ry→Wy→Rx→Wx` 的 ghb 环。因此 P 禁止 (0,0)。

仅删除线程 0 的 Fence 后，该结果合法：选 rf 为两个初始化写，co 为每对象初始化后接唯一写；ghb 非初始化部分形成 `Ry→Wy→Rx→Wx` 的链，不再有 Wx→Ry。po-loc 无环且无 RMW。因而只删除一个静态 Fence 就改变观察集合；没有“Fence 不产生写值所以可以不观察”的推理规则。

### X6：拆开原子 FAA 的读写可产生丢失更新

两个线程各执行一次 FAA(x,1)，初始 x=0。若两者都读初始 0 并写 1，co 必使一写在另一写之前。设 W0 co→W1，则 `R1 fre→W0 coe→W1`，与 `(R1,W1)∈rmw` 冲突，违反 `rmw∩(fre;coe)=∅`。对称 co 顺序同理；故正确 FAA 的最终 x=2。

把每个 FAA 错误替为不配对的普通 R(x);W(x,read+1) 后，两读为 0、两写为 1 存在合法先读后写执行，final(x)=1。RMW 配对不是可忽略的解释注释；即使静态 R/W 数量未变，删除关系也改变模型。

### X7：终端观察相等不意味着错误前缀也相等

若语言新增中途检查，`x=1; assert(x==0); x=0` 与 `x=0` 的终端 x 相同，但前者存在错误前缀。此处只是解释模型边界的顺序例子，不是本有限共享语言中的可接受程序。本文只证明终端性质；不能据此授权带中途失败语义的测试结果。

## 7. 未来规则证书及独立核验义务

本阶段只设计格式，不实现检查器。一个变换证书应至少包含：

* 两个形式化程序的不可歧义编码、输入域、对象表、线程全集、类型及观察投影；不能仅含两个 C 文件名。
* 变换规则名、局部控制区域的入口/出口/完整节点集、上下文恒等承诺和变量重命名表。
* 对 T-FAA-DIAMOND：两分支互斥穷尽、无额外事件、每分支唯一 FAA、同对象/宽度/A/配对、前状态自由变量、总性、phi 真前驱及活跃值出口清单。
* 表达式改写所需全称等式及证明对象；将来若使用 SMT，其求解器及证明检查可信边界必须单列，不能从一次 SAT/UNSAT 文本推导全部规则前提。
* 双向执行图运输规则：如何由输入、路径及实际选择确定 h_G，如何同时运输 po/rf/co/rmw，为什么所有活动事件均覆盖；不能提供一组已观察到的 h 就声称全路径覆盖。

独立核验器必须从两个程序重新检查全部语法和数据流侧条件，不能只信候选生成器给出的“无副作用”或“死临时值”布尔标记。规则前提失败时，拒绝该**规则证书**并不自动证明两个程序不等价；它们也许经其他定理或完整行为判定仍然等价。反过来，一个规则证书通过也只证明这里规定的抽象程序关系，不自动证明实际 C/LLVM/Q 表示满足这些形式化程序。

## 8. 解析审阅结论及未闭合边界

T0–T4 在明确有限语言中均已给出双向或相等性解析证明。T3 提供了不同静态潜在事件数量的非平凡等价例子，并显式保持完整全局 rf/co/fr、RMW、A、Fence、顺序、路径与活跃结果；因此不是“两个最终计数值相同”的推测。X1–X6 分别攻击地址独立、实际事件合并、返回值、guard、Fence 与 RMW 关系条件，X7 攻击观察范围外推。

尚未证明且本轮不借外部 Γ 掩盖的问题包括：任意共享事件重排、一般共享操作消除/合并、别名或指针计算、带循环的变换、带中途异常/断言的错误前缀保持、抽象语言到真实 GNU C/LLVM 的桥接，以及固定公理 TSO 与另一个独立操作模型的一般等价性。后者需要单独的证明，不由本文件的图运输引理解决。

这里得到的是可用于未来测试生成的**语义保持规则库设计**。关系运输、纯表达式等式与控制菱形的上下文替换是已有原则的具体应用；是否有独立测试选择算法创新，应由语义特征选择机制和后续研究决定，不能由本文件的正确性证明直接推出。

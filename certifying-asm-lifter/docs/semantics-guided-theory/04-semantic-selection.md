# 从合法全局图到有限测试集合：选择算法及保证

本文件设计数学算法，不提供生成器实现、不调用目标工具。依赖
[模型](01-model.md) 和 [精确行为判定](02-independent-decision.md)。
“有语义依据的选择”与“发现更多实际工具缺陷”是不同命题；本轮只证明前者。

## 1. 有限候选域

预先固定线程数上限 t、对象数上限 m、输入位数 k、程序序列化长度 s、表达式
深度 d、观察接口 O、结构特征大小 h 和输出测试预算 B。变量/对象/节点名字来自
长度界内的有限集合，字面量仍可取全部 B32；不以小常数取值作为读响应边界。

令 `G(s,d,t,m,k,O)` 是满足上述界及 01 良构条件的全部程序。按固定字典序枚举
编码，丢弃**已证明不良构**的编码。输入域谓词、初始化及观察表达式的编码也计入 s；
不允许在界外附加任意未编码函数。若有限字母表大小为 a（含有界名字及全部
32 位字面量），则候选数

`K ≤ Σ_{j=0}^s a^j`。

这个粗上界很大，但有限；没有声称可实用遍历全部 bv32/程序语法空间。实际日后
只能选择更小的预登记候选域、可靠约束求解或受限预算，并明确未遍历部分。

## 2. 合法执行语义特征

### 2.1 有限关系模式

在合法图 G 中选择至多 h 个**互异活跃内存端点**，保留以下信息：

* R/W、初始写、FAA/A 标签、相等的线程/对象分区；
* 端点间 po、rf、co、fr、rmw、mfence、K 的有/无边；
* 可选的有限值分类，例如等值类、零/非零；不能把该分类当成精确值语义。

将选中端点按全部至多 h! 种编号重命名，取字典序最小的完整编码，得到一个
**诱导关系模式**。明确记录无边可区分“有 po 的 Store→Load 但不在 K”与受 Fence
约束的同一语法顺序。对象名称、线程名称及静态文件位置不属于这个模式。

`F_h(P)={canon(G|X): u∈D,G∈Exec_T(P,u), 1≤|X|≤h}`。

某模式出现的充分证据必须包括完整合法图及 X；不能只验证该小子图满足 CAT，
因为局部图可能没有全局扩展。完整性依赖 02 对全部图的判定，而不是只求一个
观察代表：同一终态可能有不同 rf/co，不能用观察集合去重丢掉模式。

该定义捕捉跨线程读取来源、相干次序、from-read、RMW 相邻边界及排序缺口。
它不意味着凡具有相同 h 节点模式集合的程序语义等价，更不意味着它们会触发
相同编译器代码。h 之外的结构和表达式差异仍可能重要。

### 2.2 控制与变换特征

对两个潜在位点 a,b，可增加特征：a 和 b 各自在某合法图活跃，但没有任何合法图
同时激活二者。该特征需要两个存在见证及一个完整排除证明；不能由语法上的 if
或某次观察直接推出。对指定的读响应到值/控制表达式的定义—使用边，可保留为
**数据流结构注解**，但不把可能被代数消去的引用称作真正数值影响。

可另外维护 03 中已证明变换的有限类别集合 V（如 FAA 互斥复制/合并）。选中的
一个程序及其变体作为一个关系测试包，保留两个原始表示及变换证明。这增加表示
差异覆盖，不虚报新的并发行为。预算若按包计数，近似定理也按同成本的包计数；
不能把一个双程序包与一个单程序任务当作相同运行成本作实验结论。

## 3. 算法 S：完整候选池的确定性覆盖选择

```
input: finite well-formed candidate universe G, size h, budget B,
       preregistered finite-encoding nonnegative rational feature weights w
for P in G in canonical order:
    graphs[P] := ExactGraphs(P)                      // Algorithm E in 02
    F[P] := exact graph patterns plus selected proven control features
    retain proofs/witnesses for all facts used
optionally remove equal-feature/dominated candidates under the conditions below
selected := empty; covered := empty
repeat at most min(B, |G|) times:
    choose remaining P maximizing sum(w(f) for f in F[P] \ covered)
    break if this maximum is zero
    selected.add(P); covered := covered ∪ F[P]
return selected and their exact semantics, properties and evidence
```

这不是“普通程序枚举后随机选取”：选择量来自合法**全局**图中的关系模式；未知
路径不会被当作可实现模式，没有全局见证的候选不能贡献覆盖。枚举只是保证有限
域完备的基础实现，贪心决策与语法复杂度无关。此机制仍属于标准最大覆盖方法
在并发图上的实例化，不据此声称新近似算法。

**定理 S1（有效性）。** S 返回的每个程序良构、每个被声称覆盖的存在模式都有
完整合法图、每个排除型控制特征对完整图集成立。

证明：候选良构门禁和 E 的可靠性给出前两项；模式是合法完整图的明确投影。
排除型特征由 E 的完备性对全部图核验；选择只作集合并，不产生新语义事实。□

**定理 S2（终止）。** 有限 G 中每个 E 终止；每个图有有限个 ≤h 子集和编号；
每次选择删除一个剩余候选；故 S 有限终止。若日后施加资源截断，不满足 S 的
完整输入条件：应返回未完成范围，不能沿用以下最优覆盖保证。□

**定理 S3（覆盖近似，仅限同成本、完整已知候选池）。** 设 B≥1，OPT 是从该池
选择至多 B 个候选可覆盖的最大权重，c_i 是贪心选 i 个后的覆盖权重，则

`c_B ≥ (1−(1−1/B)^B) OPT ≥ (1−1/e) OPT`。

证明：取最优集合 O。尚未覆盖的最优特征权重至少 OPT−c_i；这些特征包含于 O
中至多 B 个候选的剩余特征并集。非负权重使并集权重不超过各剩余权重之和，
故其中某候选边际收益至少 `(OPT−c_i)/B`。贪心收益不小于此值，因此
`OPT−c_{i+1} ≤ (1−1/B)(OPT−c_i)`。从 c_0=0 归纳得首式；
`1−x≤exp(−x)` 给第二式。若提前零收益，未覆盖最优特征也为零；若候选少于 B，
选完即最优。□

权重限定为有限编码的非负有理数，所有和及比较均可有效计算；不默许不可计算
实数作为权重。上述运算次数上界之外，位复杂度须计入有理数编码长度。
这是标准证明，保证的是模式覆盖，不是缺陷数、首次触发时间、实际覆盖代码行数
或任何目标工具收益。权重必须非负；未知实际成本、成本不同的测试包、部分候选
或不完整特征集合不满足此定理，不能照搬 1−1/e。

## 4. 有条件的去冗余与更有目的的候选构造

**覆盖去冗余。** 同成本且只优化本节目标时，若 F(P)⊆F(Q)，删 P 不降低任何
预算的最优覆盖：任意含 P 不含 Q 的解用 Q 替换；若 Q 已在解中，直接删 P，
并集不减、数量不增。平等时仅保留固定最小编码。该操作不证明 P/Q 行为等价，
更不能删除用于检查某个编译表示差异的唯一变体。若还要求变换类别/来源类别，
先将这些要求纳入目标或分别保留，不可偷偷以小模式等价代替完整语义等价。

**精确行为去重。** 只有观察接口一致且已证明 B(P)=B(Q)，才可称观察等价；若
还需要保留环境干扰的事件历史，则必须使用 03 的更强图同构条件。最终值相等
不是删除 RMW 中间写或同步事件的理由。

**算法 R（按关系模式构造候选）。** 预先枚举所有有限大小 h 的模式 f。对每个 f
求解有界命题

`∃P∈G, u∈D, Gexec∈Exec_T(P,u), X: canon(Gexec|X)=f`。

可由完全有限程序/图枚举决定，或将有界程序的语法、良构、02 的图约束和模式
嵌入同时编码。每个 SAT 的程序、图和嵌入必须从语法独立重建验证。UNSAT 需有
完整搜索/证明证书；UNKNOWN 只表示此模式未解决。对每个可实现模式选择一个
满足程序，得到 pool_R，再用 S。

**定理 R1。** 当每个模式查询完整决定，pool_R 的 F_h 并集恰覆盖 G 中所有可实现
的 2.1 关系模式；所有生成程序合法。证明：SAT 的可靠性给一方向；任取 G 中可实现模式，
其程序和完整图是该查询的满足赋值，完备判定不能返回 UNSAT，故生成池包含一
个实现它的程序。□

R1 不包括 2.2 的互斥控制或变换类别：两个表示可有相同 F_h，但只有一个存在
互斥的潜在静态位点。按每个关系模式挑见证可能总选另一个。要覆盖增强特征，
必须另增相应存在见证与全称排除的精确候选查询；本轮不声称 R 自动完成此事。

R 会优先寻找特定 rf/co/fr/RMW 结构而非随机拼语句，是明确的语义定向构造。
但“一模式一个见证”的池可能没有同时覆盖多个模式的最佳程序。因此 S3 若应用
于 pool_R，仅相对于 pool_R 的 OPT；**不**自动相对于整个 G 的 OPT。若想取得
后者，必须每轮精确最大化整个 G 的新增模式数并证明最优性，不能只用启发式。

## 5. 一个区分语法选择与语义选择的解析例子

x=y=0，T0: W(x,1);R(y)，T1: W(y,1);R(x)。双零图取两读来自初始写，故各有
一条 fr 指向另一线程的写；两个 W→R 的 po 均不在 K。U 无环；Tso 中只有
初始 rf、co 和这些 fr，仍无环，故该模式可实现。

在两个线程的 W 与 R 之间各插 full Fence 后，mfence 增加两条 W→R。上面的
两条 fr 与两条 mfence 形成四边环，双零模式不再可实现。两程序的对象/线程数、
读写种类及对应静态访问仍非常相似，但 F_h 明确区分合法关系模式。S 可为了
覆盖尚未覆盖的 Store→Load 缺口选择前者；为了覆盖 full-fence 约束选择后者。
这只说明算法使用了语义信息，不说明它能发现一个真实工具错误。

## 6. 计算复杂度与剩余障碍

记单候选精确图判定的最坏成本 C_E、合法图数 J、每图端点数 ≤N、边关系/颜色种类
为常数 r。枚举并规范化全部 ≤h 模式的直接上界为

`O(J · Σ_{i=1}^h C(N,i) · i! · r i²)`。

完整池成本为 `O(K·(C_E+C_feature))`，保存集合后朴素 S 为 `O(B·K·|U|)`；
U 为有限实际特征并集。若显式比较两两支配，另需 `O(K²·|U|)`。
这些是实现方式的保守上界，不是复杂度下界或实际成本预测。h 固定不能消除
图枚举的指数因子，按观察去重也不能为图模式计算保完备。

R 的模式数可用有限标签数 ℓ 的 `Σ_{i≤h} ℓ^i·2^(r i²)` 再乘对象/线程分区数
粗略界定；直接求解每个模式最坏需要再次遍历候选图，可能比 S 更贵。其目标是
定向表达需求，不是未经证明的加速。候选缓存、SAT 学习、模型商约简和增量求解
都需另给不丢模式的证明，当前不承诺。

尚未解决：哪些模式真正预测验证器语义错误；h 如何选择；用关系模式导向是否
胜过 diy7 式循环生成；把程序及变换包的实际运行成本纳入选择；在有限工程预算
内得到足够丰富的图证据。这些是第二阶段前的设计/实证问题，不是本节定理前提。

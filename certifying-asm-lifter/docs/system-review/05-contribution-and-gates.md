# 理论与工具贡献分别决策

日期：2026-10-20；基线 `25e67f8cf379c74857dd78bdf6e83f334555a269`。
本轮决定：**通用非双射新算法路线暂停；受控系统开发具有条件性 Go；
当前论文投稿成熟度 No-Go。** 这里的 Go 是可行性判断，不越过用户的下一阶段批准。

## 1. 不再主张的理论贡献

开放读取符号化、事件匹配、路径覆盖、SMT 等价、有限组合和 TSO 关系输送均已有
充分相关工作。[已有组合审查](../combination-review/00-delivery.md) 的 No-Go 继续有效。
本轮 [E2E-SAFE](01-end-to-end-guarantee.md) 是对实际系统的条件式可靠性说明，
精确区分宿主、运行时、模型、查询和结论方向；它有工程上的必要内容，
但不宣称超越 PAA/JTFG、VALID、Stellite、SEQ、Kater/KATI 的算法机制。

系统论文不必以新数学引理为唯一价值来源；正确性论证仍必须充分，
并且实际实现保证不能超过已经落实的前提。

## 2. 可以发展、但仍缺证据的系统贡献

| 可主张能力 | 目前已有证据 | 尚缺的实质证据 |
|---|---|---|
| 从真实 GNU 接口到实际并发验证对象的可审阅链 | 原始 CK 单例程、真实 Clang/最终 Dat3M、类型/宏/输出/实例受限核对 | 多上下文/参数/真实客户端；完整宿主与查询绑定 |
| 小型独立认证层隔离候选转换错误 | 独立参考语义和实际片段/端点重解释、受控坏例 | 更广真实接口、良性变体、实现审计、无假 SAFE 的真值集；TCB 仍非机械精化 |
| 清楚、可复用的证据格式/信任边界 | 原始产物、哈希、查询和拒绝日志已保存 | 面向第三方的稳定 schema、版本兼容/拒绝、干净环境重查和替代候选接入 |
| 对现实并发验证工作流的帮助 | 历史真实 Dat3M 转换错误说明风险；原始 FAA 无手改通过 | 新增真实任务/性质、比较无 Checker 与原始工具、开销及人工工作量 |

可复用不是仅把内部 JSON 发布出来；需要另一位使用者能据同一契约判断适用域、
产生所需对象、解释拒绝，并在不相信 lifter 的情况下检查证据。
“独立检查器”也不等于没有 TCB：前端、参考语义、导出器、编码器、求解器和实现
仍须明确保留。

## 3. Go/No-Go 门槛

以下是本项目的内部决策标准，不是会议保证录用的数量门槛。

**进入下一次受控实现（条件 Go）：**

1. 接受 D₀ 和 [01](01-end-to-end-guarantee.md) 的信任边界；
   先补 main/生命周期清单、用户监视器及实际查询任务，不先增加指令。
2. 每个扩展对应一个具体未修改上游对象与可检查契约；按
   非固定绑定/有限宿主和多上下文的实际依赖顺序推进。
3. 维持可靠拒绝；出现范围外对象不删语句、不增未经证明前提。
4. 用户审阅批准。当前尚未进入实现。

**考虑形成完整系统论文（全部需要，当前尚未满足）：**

- 至少一个真实程序 task 满足程序级条件安全转移全部门禁，并清楚发布 Γ；
  另一方向有独立源反例核验或明确不发布可信 FALSE。
- 至少两个来源独立的真实项目/客户端谱系有实质结果，
  包含未修改上游调用方，而不仅是两个自建 FAA harness。
  覆盖多个实际存活调用/上下文、非固定输入以及参与控制或地址的输出；
  模板血缘重复不充当独立证据。
- 预先界定母集并完整报告失败；扩展带来的收益在留出对象上可见。
  如果只支持原语而不能支持有意义的有限客户端，必须降低主张。
- 有与原始 Dat3M、相同候选无 Checker、适用 lifting 的公平比较；
  对不可比语义明确 N/A，真实缺陷与人工故障分开。
- 检查成本可由预注册预算衡量且不吞没实际使用价值；目前没有测量，
  不预先声称低开销。独立重查与打包可在干净环境完成。
- 没有已知未修复的错误 SAFE；发现此类问题即暂停释放、保留失败证据。
  零观测错误只是必要工程证据，不能代替证明。

**No-Go／缩小贡献的触发：**

- 整程序结论只能靠“相信整个 GNU→Q 转换正确”成立，实际证据只验证了局部；
- 主要收益来自手工改上游、填映射、固定本来自由的输入或隐藏不支持配置；
- 同保证的既有工具组合可以合理成本完成同任务，而本系统无可复用性、可信边界
  或自动化方面的可验证增益；
- 完成 P0/P1 后仍只有同一 CK 原语和自建模板；或者成本仅能处理无使用价值对象。

这些触发不否定现有研究/复现材料的价值，但不支撑独立高水平系统论文主张。

## 4. FSE、CAV、ISSTA 的定位判断

截至本次查阅，官方信息支持以下**定位分析**，不是投稿承诺：

- [CAV 2026 CFP 的 Short Tool Papers](https://conferences.i-cav.org/2026/cfp/)
  明确允许工具论文不含新研究，但要求实用性、正确性依据、可复用细节及评测，
  很早期未经验证的工具不适合。该已发布届次可作为定位参照；
  不能把本项目尚未发表的条件证明当成它要求的已审稿依据。
  若真实链和复用性成熟，CAV 工具路线最直接；正式投稿要再核对目标届次规则。
- [FSE 2027 Research Papers](https://conf.researchr.org/track/fse-2027/fse-2027-papers)
  接受理论、经验和实验研究，但仍要求原创且重要的研究贡献。
  对本项目，更有说服力的是可复核的真实验证增益/风险消除和严谨比较，
  不是换一个“证书合成”名字。
- [ISSTA 官方定位](https://conf.researchr.org/home/issta-2027) 与程序测试分析系统相关；
  本轮打开的 [2027 Research Papers](https://conf.researchr.org/track/issta-2027/issta-2027-research-papers)
  正文仍为 TBD，因此不编造该届工具类别/新颖性豁免。
  若主要成果是分析可靠性、真实缺陷与严格评测，应按具体投稿届次再评估。

现有材料尚不支持选择一个会议就宣称达到级别。
本轮的积极结论是：**可以沿可信边界明确、真实对象自动认证的系统路线继续
受控投入，且有可具体修补的首要缺口；不能据一个 CK 成功案例发布系统有效性结论。**

## 5. 停止点

本批交付完成后停止。下一步只能在用户批准后执行 P0 和选定的一项受控能力验收；
不运行全量实验，不恢复通用非双射新算法，不改写历史证据。

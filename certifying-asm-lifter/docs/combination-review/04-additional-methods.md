# 补充方法核查：TSO 迁移、并行数据流与最新分解

本轮补充检索至 2026-10-20。以下均使用作者/会议原始资料；
不依据自动生成的论文摘要站判断定理。查阅范围和副本哈希见
[来源记录](evidence/sources.json)。没有重建或运行这些工具。

## 1. Portability of Optimizations from SC to TSO

[原文](https://arxiv.org/pdf/2504.17646)，核查 §2–3、Definition 3–4、
Theorem 1 及附录接口；未逐行审计全部附录证明。
论文针对 pre-trace 的变换效果，在不引入/删除写、也不发生其 `tuwri` 效果的
限制下，把 SC 的优化安全性迁移到 TSO。其安全方向是优化后行为包含于优化前；
语义使用共同事件上的 rf/mo 比较，RMW 为单节点，Fence 通过专用位置的 RMW
解释。pre-trace 抽去条件后还需宿主顺序语义连接。

**可接入方式。** 将实际候选的事件增删/po 变化恢复为论文的 effect，逐项检查
它的语法限制；另证 SC 保证与事件/数据/guard 对应。这个路线比泛称
“所有顺序优化都能用于 TSO”强得多，也已处理跨线程上下文相关条件。

**不能省略的桥接。** 本项目的分裂 RMW、失败 CAS、真实 Fence、监视器及
`S⊆Q` 均不能直接替换论文符号。要用其优化方向取得 SAFE，需要对**反向
变换**证明 SC 前提和相同限制；不能只把结论箭头翻过来。
合法写消除、失败 CAS 端点变化等仍可能落在定理范围外，属于前提不满足。
这项工作不声称自动从无可信来源的 GNU/LLVM/Q 合成 effect；
其未提供该工具接口不构成独立算法创新证据。

## 2. WaveCert

[原文](https://arxiv.org/pdf/2312.09326)，核查 §4 的 Definitions 1–6、
cut-simulation 与覆盖，§5 的 Theorem 3 和 Algorithm 1。
它把顺序源程序与异步数据流目标在规范调度上对应，再用动态分数权限证明
合流，从而覆盖其他调度。源为确定性的 SC 程序，目标也使用 SC 访存；
不是 TSO 共享程序间的精化定理。

其 cut-simulation 允许不同步数，初始/终止覆盖和分支条件完整性不是事后补丁。
来源 hint 可帮助选择规范调度，但规范调度对应仍需要检查，不能仅凭 hint
认定目标等价。多 firing 的计数在合流定理中通过操作多重集约束体现。

**可复用部分。** 规范见证＋覆盖其他行为、cut-point 覆盖和权限约束提供了
现成的结构分解思路。**适用边界。** 两线程 FAA 的合法结果依赖谁先取旧值，
本来就不应要求所有调度汇聚到相同可观察输出。不能未经证明把权限合流替换
为 TSO 的 rf/co 相容性，也不能将其最终内存观察直接视为本项目错误监视器。
不采用这条路线的理由是语义前提不符，不是它不支持 GNU 语法。

## 3. DESTIVA：Spatial and Temporal Decomposition for Faster Translation Validation

[作者原文](https://mikekben.github.io/resources/OOPSLA_DESTIVA.pdf)，
OOPSLA 2026。核查 §3–4，特别是 Property 3.1、Theorems 4.7/4.9。
其空间分解围绕实际变更集合扩展数据依赖，再对提取函数验证；时间分解按编译
阶段选择检查点并用传递性组合。形式域也是无环程序，但语义是顺序函数/内存。
可靠性显式依赖变更集合覆盖真实改动，即 `P\A=P′\A′`。

**可接入方式。** 可作纯计算/顺序适用区域的缩减候选，或在固定语义桥接后使用
分解定理。**不能省略的桥接。** 本轮允许错误/不完整来源信息，不能直接信其
变更标签。需要独立证明不变部分相同与变更覆盖；若做不到，扩大 A 到整个程序
仍是既有保守回退，不是新算法。其数据依赖重排也不能未经 TSO 排序证明移植到
共享片段；不同地址的 W→W 顺序具有并发意义。

该论文因此强化了创新性风险：泛称“利用变化信息缩小证明＋分阶段组合”已有
明确算法和定理。它并未免费解决不可信提示的 TSO 认证，但当前缺口首先是
可信前提/语义桥接；尚无证据表明需要本项目独立的新机制。

## 4. 对主结论的影响

这些工作加入 [01 的强组合](01-strongest-combination.md) 后，可增加特定子类的
证明规则和缩减候选；不能省掉统一语义、观察方向、实际对象与覆盖条件。
本轮没有把各自模型直接叠在一起组成接受定理。

它们未提供一个现成的完整 GNU→Dat3M 工具，也没有推翻本轮窄引理；
它们进一步说明，决定独立创新性必须比较**具体的充分条件与分解成本**。
仅实现无提示匹配、把多个局部结果串联、或把范围扩到更多 asm，不足以立项
为新算法论文。当前仍为 No-Go（本轮候选独立算法创新）。

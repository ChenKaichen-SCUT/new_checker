# G-CLOSED：全局可达性与目标观察排除的受限解析证明

基线 `ebbe82856ea15e31b6ff5da352ee9ae51e0b08b9`。这是新的诊断定理，
不修改 E2E-SAFE、PD-SAFE、ACTC 或 L1–L4。代码在 `guarded/closed.py`。
证明先说明本轮实际实现的范围，再说明较一般的条件式组合引理。
本轮没有从局部 SAT 推出任意 C 程序的可执行缺陷。

## 1. 三种观察及输入域

开放历史观察记录每条活跃路径的 R/W/O 顺序、宽度、地址、写值、读响应、
RMW 配对、A/RMW 标签，以及 O 的布尔条件。`GUARDED_OPEN_INCLUSION`
只表示源历史包含于目标历史集合；这是安全转移所需方向，**不是双向等价**。
它比单纯最终值观察严格，可能拒绝对更弱观察合法的优化。

G-CLOSED 的初始实现域 D_C0 进一步要求：每个源 worker 只有一条完整直线路径，
全部用户共享操作为已检查的 FAA 和允许的不可变输入读取；worker 无错误监视器，
main 的所有创建、正常 join、初始化、最终共享读取、断言及返回均由旧 main 门禁
完整检查。只有 main 在全部 join 后产生用户错误。全局图最多 64 个内存端点。
源捕获、未定义行为/别名规则、对象宽度和正常线程库域仍服从原八项 Γ。
未知别名、循环、截断、未解释语句、worker 早期错误、路径不完整均不能生成
本级反例。G1 接受的分支 worker 不因此自动属于 D_C0。

这里要排除的目标观察是单个布尔值：**至少一个实际用户断言失败**。
源见证给出实际初始化、无外部输入的两次 FAA 增量、线程入口、读值和 rf/co/fr；
有效地址用源对象身份表示，任意满足 ABI 的互不重叠分配均可实例化。
没有声称某个特定宿主进程的物理地址、原生调度轨迹或完整终态不存在于目标。

## 2. 源图构造，不是构造替代 Q

从真实 AST 按 G1 的表达式规则得到每个源 worker 的公共端点。
从独立检查的 main 得到初始写、创建、join 和用户监视器。以实际
ThreadCreate/ThreadStart 关系确定激活身份，绝不以观察到的调用次数代替源码清单。
每个声明对象有一个初始写。读值是相应宽度的独立变量，写值来自源表达式。

对受支持的正常生命周期分支，复用旧门禁已检查的私有协议解释：

- 每个线程有独立的 2 位 `__com_worker#id`，初值 0；main 创建时写 3。
- worker 启动读的低位为 1；结束的 A/RMW 读写执行 `v & 2`。
- main join 的 A/RMW 读写执行 `v & 1`；正常分支要求原值高位为 1、低位为 0。
- worker 公共事件位于启动和结束之间；main 的最终读取位于全部 join 后。

这些规则逐项对照实际 Program 的字段、表达式和线程链接检查。私有名字没有
与公共对象混同。它们对成功源线程生命周期的意义仍是原 Γ_runtime，未新证明
整个 pthread 模型。输出文件明确标注 `derived SOURCE graph, never actual Q`；
真实 Q 始终只来自同次后端的 before/after 快照，不会用此图替换。

## 3. 有限 CAT 编码及其正确性

固定文件散列：tso.cat = `8561d85057c449c0828b888c61e3cfeda8b73750474353eee1dd3f0383b192ac`；
x86fences.cat = `b7d347726619c89e336bb19fd0ed5284d0b2fb893f06c957644ab769de691766`。
运行时同时核对 build pins 与保存的 CAT 文件字节。D_C0 没有用户 Fence，
因此 mfence 为空；未知 fence 不会被忽略。它不是适用于任意 TSO 文件的编码器。

令 E 为所有执行的内存端点，po 为各线程列表的严格先后关系。每个读 r
恰好选择一个同对象、同宽度写 w；布尔变量 rf(w,r) 蕴含 value(r)=value(w)。
每对象写具有互异整数秩，co 定义为秩小于，初始化最小。不同对象不建立 co。
fr 定义为 rf 的逆与 co 的复合，不能另外自由选择。对每条 rmw(r,w)，加入
`not exists v. fre(r,v) and coe(v,w)`。再给下面两个图独立的拓扑秩：

```
U = po-loc | rf | co | fr
T = K | co | fr | rfe
K = po & ((R*M) | (W*W))
  | po & (W*R) & ((M*A) | (A*M))
```

**有限编码引理。** 对声明的有限端点集合，编码可满足当且仅当存在满足上述
值/路径条件与固定 CAT 的图。证明分两向。满足赋值给出唯一供值、严格全序及
派生 fr；每条有向边严格提高有界拓扑秩，故不存在环；rmw 的逐对否定恰是
CAT 的 empty 条件。反向取合法图，每地址 co 线性序给出互异秩；有限无环图
存在拓扑排序，将其序号赋给 U/T 秩，所有公式成立。这里不靠枚举测试证明。
排序秩只需包含所有节点的区间；不同对象使用相同 co 秩不产生跨对象边。

**独立图核验。** `verify_graph` 不信任这些 SMT 秩。它从真实源重新构造
端点与表达式，检查证书事件集合完全相等、全部具体值宽度合法、写表达式成立、
rf 唯一及同地址同值、co 反自反/全序/传递/初始化最小、fr 完全派生、po/rmw/A
逐项完全相等，再对 U/T 直接做 DFS 检查无环并检查 atomicity。
因每项正好对应引理的图条件，该独立核验接受即足以得到同一个合法源图。
此实现没有机器检查的程序精化证明；其正确实现仍属于原 Γ_check。

## 4. 可达、不可达和未决的不同充分条件

首先求解源**公共投影**：删除全部私有协议端点，但保留公共初始写、worker
全部公共行为、main 的公共读取及所有源码路径条件。公开对象与协议对象分离，
所以公共读的 rf 不可能来自被删的私有写。完整 co 的公共限制仍是全序；fr
的公共限制恰为公共 rf/co 派生。完整图无环蕴含子图无环；公共 rmw 的 CAT
条件也保留。因此，每个正常完整源执行都映到该公共投影的一个解。
这是**过近似**，不是声称删除线程协议后得到等价执行语义。

给定已独立核验的开放差异 w，绑定其中出现的源读响应。若开放证书只指定
部分读取，则检查的是这些赋值的所有扩展，报告中不能伪称其余值已固定。
对象布局不参与本域的数值计算，名义对象有同一个有效、不别名解释。

**G-UNREACHABLE。** 公共投影与 w 的绑定 UNSAT ⇒ 不存在满足 w 的
正常完整源执行。反证：任何这样的执行按上段投影得到满足赋值，矛盾。
这个结论不意味着其他开放见证都不可达。它限定于完成 main 的 D_C0 域，
不覆盖未建模的提前失败、外部输入、创建失败或无限执行。

公共投影 SAT 只给出可能性。随后加入全部实际检查过的私有协议条件、同一个
全局 rf/co/fr 和源 main 错误观察，求 SAT，再独立核验具体图。若 SAT/核验
成功，则在原 ISA/runtime/domain/capture/check 前提下有合法源错误执行。
若完整补全 UNSAT，**不能倒过来声称开放见证不可达**：本实现只搜索正常协议
分支，返回 OPEN_DIFFERENCE。超时或证据不完整保留 UNKNOWN/受限状态。
这避免假设“某种私有协议补全必然完整”以错误解释 UNSAT。

实际历史例：x 初值 0，两线程分别 FAA(+1)。找到的 co 为 init < worker2 <
worker1，读取分别 0 和 1，写入 1 和 2，main 在正常 join 后读取 2，违反
`x==0`。完整源图有 20 个内存端点，包含三个初始对象及全部协议内存事件。
这证明受限源错误可达，不需要先假设源安全或用后端 FAIL 反推。

将首个源 FAA 读取约束为 7 后，开放差异仍成立而公共图 UNSAT。这也有解析
解释：两个 locked FAA 的读来自各自 co 前驱。若读跨过另一线程写，则违反
rmw∩(fre;coe)=empty；读自己或 co 后继违反 po-loc/com 无环。仅有初始写和
两个不同线程写，故读取只能为 0 或 1（32 位加法），7 不可达。这不是推广
PD 值修复规则，只说明此固定反例为何不能具体化。

## 5. 排除所有目标观察，而非比较一个执行对

独立的 `target_queries.py` 复用原 P0 查询核验逻辑。唯一语义用途变化是
输入门禁标为 **ACTUAL_TARGET_HOST_MONITORS_CHECKED**，不要求错误的 asm
已与源等价；这是在验证目标自身的主程序/监视器集合，绝不伪造 D0 主机等价。
保留原 Task/Program/run、文件散列、属性类型、全部监视器、私有 property 变量、
assumption literal、错误查询、bound 查询、调用顺序、SMT 栈和实际结果核验。
缺少 bound 完整性、未知结果、错绑均关闭目标排除门禁。

在原实际安全与 bound 均为 UNSAT 后，再从同次真实 audit 构造：

```
Q.program AND Q.memory_model AND Q.variable_bounds
AND OR(user-monitor.execution AND NOT user-monitor.condition)
```

这里删除 symmetry 条件，不能依赖某个对称代表恰好遗漏匹配观察。此式 UNSAT
排除的是全部目标用户错误执行，包含不同线程交错、rf/co/fr 及所有实际路径。
它没有固定目标去匹配某个源事件映射，也不只排除一个挑选的目标执行。
该式来源和用户监视器集合被检查，但 Program→SMT 的完整性、前缀覆盖和求解器
可靠性仍为原 Γ_encode/Γ_solve，不能由本次 UNSAT 自证。

**G-CLOSED 定理。** 若 D_C0 的源具体图独立核验成功，Bad_source=true；
若实际目标查询/完整界限绑定成功，上式 UNSAT；若原八项 Γ 的适用条件成立，
则存在源的完成错误观察而不存在目标的任何同布尔错误观察。因此源错误行为
不包含于目标错误行为，报告 CONDITIONAL_CLOSED_ERROR_DIFFERENCE。
证明：前半由源提取引理、独立图核验和 Γ_ISA/runtime 给出源见证；假设有目标
匹配错误执行，由 Γ_encode 和实际属性绑定得上式满足赋值，与 UNSAT 矛盾。
不存在假设源安全的步骤，也没有以 PASS 文本为前提。

若不执行目标排除，只能报告 REACHABLE_SOURCE_ERROR_ONLY。若目标有其他合法
错误执行，当前布尔观察不足以区分，必须保持该受限状态；不能把一个不匹配的
源—目标执行对提升为转换错误。完整状态/轨迹观察的目标排除尚未实现。

## 6. 全局兼容性引理和不可越过的边界

若对一个完整源执行的每个激活，G1 给出相同公共观察的活跃路径对应；若完整
宿主边界已另行满足原 C0–C4/HCC 条件，则把这些每执行双射与宿主双射并起来。
不同激活的事件身份不重叠，覆盖使其并为全局双射。用同一双射输送 rf/co，
而非每区域另选读来源；地址、值相等保证供值合法。由关系复合的定义，对
任意 (r,w)，`rf^-1;co` 在输送前后相等，故 fr 同步保持。po、R/W/A、pair、
生命周期和边界顺序保持使 K、U、T 相等（若扩展至 Fence，还需 fence 节点和
完整 po 的同样对应；当前实现不接纳用户 Fence）。双射保持环与 empty 条件，
于是固定 CAT 的合法性保持。错误监视器条件相等使错误观察同样输送。

这个引理不是“各块各自合法就可组合”：没有统一 rf/co、活跃完整覆盖、宿主
边界时，其前提不成立。G1 的成功结果没有自动完成这些程序级前提，仍不输出
L3/L4、ACTC_SAFE 或程序 SAFE；G-CLOSED 也只是条件式反例，不是安全认证。

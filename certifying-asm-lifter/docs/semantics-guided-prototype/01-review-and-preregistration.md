## 逐份审阅

已阅读全文 `semantics-guided-theory/00–07`。01 的固定对象、全 bv32、固定完整线程、
终态观察继续适用。02 的 B 与 CAT 图双向对应直接给编码规范，不能直接作为 Python
实现保证；初始化最小、两个拓扑秩、独立 fr 推导及 FAA 配对须落实。03 的菱形规则
需核验两臂、前状态、完整出口和不变上下文。04 必须枚举全部图，不能只保留每个
终态的一个代表；模式仅覆盖已穷尽程序池。05 的 SAFE 需要完整性，合法见证列表
本身不够。06 的标准覆盖贪心、关系 litmus、观察集合 oracle 不申报独立创新。
07 的操作机/CAT 一般等价和 DSL→C 桥仍未证明；本轮不借用这些未完成条件。

实现采用严格结构化 `sequence/if` 子集，无 goto/phi 语法，普通局部环境在两分支
合流处取共同定义；无环和互斥/穷尽由构造保证。接受全部总位运算，输入可为 bool
或 bv32；全部结构路径验证定义。预算限制不能变成语义限制。输入观测始终保留。

## 实施前固定的范围

候选池由 10 种线程结构的笛卡尔积产生 **100** 个不同任务，全部保留。两个线程、
两个对象，每线程至多两个实际共享操作、每程序至多两个分支。布尔输入 b 的两值
全部覆盖；即使某任务未使用 b，也不得省去。另有 9 个确定性边界原件，包括 3 线程
FAA、模回绕、SB、Fence、条件路径及活跃返回。生成 pool 文件及 `manifest.json`
在第一次 Oracle 运行之前完成并提交；以后结果不反向改变池、种子或预算。

每候选 B 最长 60 秒、最多 10,000 个图、4,096 个路径元组；A 最长 60 秒、
1,000,000 个关系候选。用完整图阻断，排除拓扑秩的无意义重复。任何中断 UNKNOWN。
独立 A 只接收 bool 输入及仅依赖输入的写值/FAA 增量：枚举每对象 co 排列，由已证明
的 FAA 直接前驱引理计算值，再枚举普通读 rf，在全部线程联合检查。值仍是 bv32，
不是小整数取值假设。这是同一 CAT 的不同算法实现，**不是独立内存模型等价证明**。

选择预算 5/10/20；种子 11/29/47/71/101；random、syntax、semantic 共 45 次选择。
semantic 优化 ≤2 端点的完整诱导关系模式，单位权；三端点模式及终值零类别、
活跃读次数、分支选择、终态数是固定留出指标，不能依据运行结果改权。
syntax 优化操作种类、相邻种类/地址关系、线程/对象数；所有策略使用同一候选池、
相同精确数量预算及种子打散顺序。零边际后仍按预定顺序填足预算，避免成本不等。

为保证比较分母，若任一候选没有 B COMPLETE 与 A AGREEMENT，则不在事后删除它；
保留失败记录、停止完整池的选择结论。所有策略共享同一离线语义测量用于评价；
semantic 所需全池 oracle/特征预处理成本另外完整报告，random/syntax 不需要该成本。
因此不宣称相同端到端时间预算，也不宣称运行时间加速或缺陷发现收益。

GO 不能仅凭自身优化指标。报告留出指标、是否稳定超过两种基线、证据与求解成本；
若只是重新加权模式数量或优势不稳定，选择方法/下一阶段研究判定为 NO_GO 或待审阅。
基础 Oracle/变换验收与选择收益分别判断。所有性质是 DSL 终态性质，不升级历史认证。

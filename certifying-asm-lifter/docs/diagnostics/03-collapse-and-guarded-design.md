# 对候选算法的反证与有限条件事件设计

状态：数学推理和算法设计。没有相应真实 CFG/guard 提取器、实现保证或
新的实际认证结果。前一稿 [01](01-model-proof.md) 的无条件模型保留为审阅对象。

## 1. 总序退化引理：不能用排列搜索制造创新

设源和目标各有 n 个公共端点，按各自真实线程次序编号 1…n。若双射 m
保存**所有**公共端点的严格程序次序，则 m(i)=i 对每个 i 成立。

证明：最小源端点必须映到最小目标端点，否则目标最小端点的原像 k>1
要求 m(1)<m(k)=1，矛盾。删除两侧最小端点，在余下 n−1 个端点上重复。
有限归纳得唯一恒等秩映射。不同数量不存在双射；同数量但秩对应种类不一致
也不存在保序的类型化双射。□

因此 01 中所有非保序候选的 E_m 恒为 false，任何输入都不能使它们成立。
若唯一保序映射 m0 类型兼容，则

    conjunction_m NOT E_m(u) = NOT E_m0(u).

若 m0 类型不兼容，则所有 E_m 恒假。穷尽更多排列增加成本而没有扩大等价
或差异判定范围。“没有写死序号”在这里只是实现外观，不能满足独立新算法
的实质要求。最小字段偏差集合可提供诊断排序，但只是一个既有代价模型下的
组合优化，没有证明真实根因或新增检测能力。

01 的 E1=b、E2=not b 量词警告作为一般关系逻辑正确，但**不是其全总序
无条件端点域中的可实现反例**。不能拿它声称当前实现解决了真实映射歧义。
下面给出需要真正放宽事件域才出现的例子。

## 2. 有限 guarded 摘要模型 D_G（设计域）

每个线程的摘要有有限潜在端点集合 V，端点 v 包含：

- 唯一动态激活/静态上下文身份、R/W/O 类型与位宽；
- 执行 guard g_v(X,U)，地址/写值/监视器表达式及标签；
- 有限程序次序、配对与屏障关系；关系只在相关端点执行时取值；
- 全部表达式的类型、定义—使用 DAG 与求值条件。

输入 X 是源关系域内的合法入口；U 为每个潜在读的有类型响应。只在读端点执行时
其响应有意义。无环直接调用与有限激活可以展开为有限潜在上下文，但必须从
真实源/LLVM/实际 Q **独立**证明展开完整；观测到的实际节点不能代替源域覆盖。
现有 FAA 可位于分支内；本设计不增加新的 ISA 指令语义。

纯表达式总化为常量、合法入口、先前活跃读响应、总 bitvector 运算和 ITE。
不以总化掩盖 undef/poison、越界或 C 未定义行为：它们必须被合法域/摘要
正确性排除，否则拒绝。目标摘要也必须独立满足这些条件。

### 必须核验的有条件定义使用规则

定义 Use(e,r,η)：表达式 e 在求值条件 η 下确实需要响应 r 的条件。叶响应
给出 η；常量给 false；严格运算向各子表达式传播 η；`ITE(c,a,b)` 的条件
在 η 下求值，两臂分别在 η∧c 和 η∧¬c 下求值。多个用处取析取。

每个响应 r 必须由拓扑上先前的读产生，并独立证明

    D => (Use(e,r,η) => g_r).

端点字段使用 η=g_v；guard 本身使用 η=true。短路条件必须按其实际语义
表示为 ITE，而不能把读未定义路径上的表达式任意求值。未知函数/别名/循环
不能成为一个无条件的总表达式叶。

**不活跃响应无关引理。** 满足上述规则时，改变任意不活跃读的填充值不会
改变活跃历史。证明按 guard/字段依赖的拓扑序归纳。严格运算由子项归纳成立；
ITE 先由条件归纳选择同一分支，另一臂不求值。若一个不活跃响应实际影响
当前求值，其 Use 条件为真而 g_r 为假，违反检查义务。故其值不影响当前
guard 或活跃字段。逐端点归纳后全部活跃事件、值和关系相同。□

该引理是消除未匹配的**不活跃**潜在端点的依据，不能删除执行中的共享事件。

## 3. 所有部分对应与完整公式

候选集合 B_G 是所有类型/宽度兼容的部分单射 μ:V_S ⇀ V_T，不预设来源、
秩、事件个数或映射是否随输入变化。每个潜在端点允许映到一个尚未使用的
目标端点或暂不匹配；每个分支都保留。资源截断必须报告 UNKNOWN。

对于 μ，将被匹配的目标读响应替换成相应源读响应；没有匹配的目标读响应
暂填固定零。零不是新的环境假设：下列公式要求这些读不活跃，无关引理才
使该填充合法。不能给一个尚未证明不活跃的目标读任意填零。

F_μ(X,U) 是以下条件的合取：

1. 未匹配源端点 guard 为 false；未匹配目标端点替换后的 guard 为 false。
2. 对每个匹配端点，两侧 guard 相等；guard 为 true 时字段、标签相等。
3. 对所有两侧匹配端点，活跃时程序次序、真实 pair、所需 Fence 关系双向一致；
   跨激活和接口边界不能凭节点局部顺序推断，须单列并检查完整关系。
4. 所有必需安全监视器与边界输出在其求值条件下相等。死寄存器无需匹配，
   但只要进入后续控制/实参/共享值/观察，它就必须出现在字段或端口中。

此处 D 是源合法域 D_S，不能取源/目标域的交集来删除不利输入。目标的
适用条件必须由 G2 证明覆盖 D_S；若不能证明，就报告定义性/域义务未完成，
而不能收缩 D。需要显式处理 target UB 时须增加其真实语义模型，当前设计
不将 UB 自动解释为空行为，也不将它当某个随意的常量。

保留某些结构只作为充分条件会导致正确优化被拒绝。报告名称必须说明这一
具体观察关系，不能由 F 失败推出一切语义定义下都错误。

最终差异公式为：

    Ψ(X,U) = D(X,U) AND conjunction_(μ in B_G) NOT F_μ(X,U).

SAT 给一个共同开放见证；UNSAT 给逐输入的活跃历史对应
`forall X,U in D. exists μ in B_G. F_μ(X,U)`。
这次 UNSAT 可被接受为**逐输入开放历史包含**，因为关系本身明确定义为该量词
方向；不能重标成“存在一个统一静态映射”或原 L3/L4。

## 4. 完整的受限可靠性证明

**前提 G0–G4。** G0 为真实对象/输入域绑定；G1 为两侧摘要对所有合法开放
输入的忠实性与潜在路径完整性；G2 为总类型/有条件定义使用及对象有效性；
G3 为独立核验的完整 B_G 和正确构造的 F；G4 为 SMT 与证书检查可靠性。
这些是待落实的检查义务，不是新增 Gamma。当前系统没有完成 G1/G2 对
一般条件共享事件的实现；因此不能实际应用定理签证。

**部分对应完备引理。** 对任意实际活跃历史之间的类型化端点同构 h，将 μ
定义为恰好这些活跃端点上的 h，其余不匹配。μ 是 B_G 中的一个部分单射。
未匹配端点均不活跃，故填零不改变目标活跃历史；h 保存的字段和关系使 F_μ
成立。证明由有限部分单射枚举的归纳完备性与不活跃响应无关引理得到。□

**公式充分引理。** 若 D(X,U) 且 F_μ(X,U)，则 μ 限制到活跃源端点后恰好
双射到活跃目标端点，并保存全部指定字段、关系和观察。
证明：第 1 项排除所有未映射的活跃端点；部分单射保证无复用；第 2 项使
映射两端同时活跃；因此既单射又满射。字段标签由第 2 项、关系和观察由
第 3/4 项保存。目标响应赋值按匹配读复制；不活跃读填零由 G2 合法。
G1 将这份摘要实例解释为真实开放线程行为。□

**G-DIFF/G-INCLUSION 定理。** 在 G0–G4 下：

- 如果 Ψ 的模型经独立重建核验，则该源开放历史没有保持读响应、公共端点及
  指定观察的目标历史对应。否则其活跃同构由完备引理给出 F_μ，与模型矛盾。
- 如果 Ψ 可靠 UNSAT，则任取合法源开放输入都存在一个 F_μ，由充分引理得
  一个保持观察的目标开放历史。这里是源→目标包含；反向包含必须交换两侧
  另证。不能因语法看似对称而省略反向合法域与非确定性条件。□

上述定理是摘要层面的闭合条件推导，不是已验证 C/LLVM/Dat3M 实现定理。
所有输入域和提取完整性前提都明列，没有假定原程序安全或目标 PASS。

**全局兼容推论（仍需原完整宿主前提）。** 固定一份合法源执行 G，在各线程
中取它实际的 X/U，得到有限活跃映射的并 h。若线程/激活覆盖、跨边界依赖、
观察与完整关系已经检查，则 h 的定义域/像互不复用，覆盖全部相关端点。
仅将同一 G 的 rf/co 经 h 运输；fr 由复合导出。对应地址、值、po、A、pair、
Fence 和生命周期保持，所以固定 CAT 所用关系及其禁环性质保持。实际协议
补全仍需原 Γ_runtime，编码/安全查询仍需原 C0–C4/Γ_encode/Γ_solve。
μ 依赖该执行的值不会破坏这一存在性推理：先固定 G，再选择 h，再统一运输
其全局关系；没有每片段独立选择 rf/co。该推论不允许从未验证的 G1 跳到 SAFE。□

若将此推论用于源错误前缀，G1 必须明确覆盖这些前缀而非仅正常终止路径，
并检查停止观察和协议前缀。不能先假定一个有错误或阻塞的前缀一定能延长为
完整终止执行。当前缺少该实际提取证明；此推论没有另行颁发程序级安全保证。

## 5. 真正区分静态秩映射的例子

源有一次无条件 `FAA(x,1)`，返回值参与后续断言。目标把它复制到 `b` 与
`!b` 两个互斥静态分支，两处都执行相同 FAA 并汇合对应返回值。b 是合法
布尔入口；没有修改内存模型或原接口。

每次执行都恰有一个 FAA。一个统一部分静态映射不能同时选择两条分支。
分别映到两个目标潜在 R/W 对的 μ_b、μ_!b 有 F=b 与 F=¬b；公共模型
`¬b ∧ b` 不可满足。逐输入活跃映射可以成立；固定潜在端点数/统一位点
双射会拒绝。若某一分支缺写，则取相应 b 的执行得到未覆盖活跃写；无论怎样
重命名都不能通过第 1 项。

这是解析设计例子，**没有生成或手写替代 LLVM/Q 验收**，没有声称真实优化
已经产生了该结构。还需要从实际 CFG 独立重建两个 guard、返回汇合和所有
上下文，才能作为真实系统增量能力。VALID/PAA 已处理相关控制/合并问题，
这个例子不能单独建立新颖性。

## 6. 算法、证书与拒绝

```text
EXTRACT-AND-CHECK(P, L, I, Q, domain):
  authenticate same-run/raw objects and complete source activation domain
  recover typed finite guarded summaries independently on both sides
  prove summary coverage, totality and conditional definition-use obligations
  if any premise absent: return UNSUPPORTED with missing obligation

BUILD-CANDIDATES(S,T):
  recursively choose unmatched OR an unused compatible target per source node
  retain every choice; hints only prioritize, never eliminate a branch
  if resource limit prevents exhaustive construction: return UNKNOWN

DIAGNOSE(S,T):
  construct every F_mu and common witness formula Psi
  SAT: propose typed assignment, complete-domain identity and failed obligations
  UNSAT: propose pointwise inclusion claim and complete formula certificate
  UNKNOWN: no semantic verdict
  localization is an independently checked minimum-deviation frontier;
  do not infer source-code root cause from its cost alone

VERIFY(raw objects, claim):
  independently reconstruct G0-G2, candidates and complete formula
  for SAT re-evaluate domain and every NOT F_mu at the supplied assignment
  for UNSAT independently solve the reconstructed Psi (original Gamma_check)
  reject a missing candidate, missing active event, false guard or stale object
  return only the stated open-relation claim, never program SAFE
```

证书包括真实对象哈希、作用域、域条件、每个潜在端点及 guard/求值条件、
全部活跃关系、候选空间生成规则/完整性、Ψ、独立义务和赋值；不信任外部
给出的节点摘要或候选列表。哈希只绑定字节，不能替代 G1。

候选上界是 `sum_k C(n,k) C(m,k) k!`，类型过滤仅减少此上界。展开、字段
比较和路径约束可能指数增长。未提出优于已有符号关系/路径匹配的分解机制。
预算耗尽须 UNKNOWN；保留所有合法目标的证明前，不能靠启发式剪枝后报 BUG。

## 7. 攻击与仍未完成的关键条件

- 若漏掉 !b 分支候选，会把正确复制误报为缺失事件；独立完整性必须重建。
- 若条件 `b && read_value==1` 被错误地当成无条件使用 read_value，可能拒绝
  正确摘要；若反过来随意填零，会接受错误摘要。Use 义务不能省略。
- 若源读 r 被两个目标活跃读复用，就改变共享观察次数；部分映射必须单射。
- 条件 CAS 的失败 A-read/成功写 pair 需要真实 ISA guard 定义，不能直接
  用本 FAA 分支例子声称支持 CAS。
- 跨线程各自找到 SAT 赋值不意味着统一 rf/co 可实现。设计只提供开放见证。
- 为不支持的 LLVM poison/对象语义补一个无约束变量，会改变行为包含方向。
  必须拒绝或给单独证明过的抽象关系，不能依靠 Γ 掩盖。

结论：一般的受限摘要层定理可闭合；实际提取/guard 证明提供者未闭合；
独立算法差异和成本优势未建立。当前不据此启动实现或实验。

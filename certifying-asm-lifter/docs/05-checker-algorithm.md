# 阶段 3：共享切点检查器

## 1. 可实现子类与输入

输入为源 GNU asm 声明 A、候选 Event IR T、由 checker 确定的 Γ。
证书是重检查提示，不是被直接信任的判定。第一版：有限直线块、固定事件骨架、
纯计算可含位向量 ite；无未知函数、任意循环、条件性事件、内存数组快照。

独立参考侧 `semantics/reference.py` 从原始指令及受信接口建立符号开放语义。
候选生成侧 `lifter/lift.py` 生成显式 Event IR。
目标侧解释器只解释 Event IR，不调用 lifter 的指令映射。
参考侧不读候选 IR，检查侧不导入 lifter。共用语法/类型工具属于 TCB，必须列出。

## 2. 独立符号执行与共享响应

建立入口符号 X（操作数值和地址），P(X) 由可信接口产生。
源与目标各自从相同入口接口运行到切点。第 j 次共享读取或 RMW 得到 u_j；
序号按**读切点**计数，不能按地址建立缓存。两侧可共用 u_j 是待证明的耦合，
其合法性由事件数、种类、地址和模式检查提供，而不是事先假设读同地址必同值。

符号状态直接作为前缀的函数：

    S_i(X,U_<i)，T_i(X,U_<i)。

无需猜测全状态一一相等；中间临时变量可不同。证书中的状态关系是可达状态图关系

    R_i = {(S_i(X,U_<i), T_i(X,U_<i)) | P(X)}。

量化输入和响应不出现在 SMT 语法内；用“存在使义务失败的赋值是否 SAT”判有效性。
纯表达式完全定义，不含除零/溢出 UB。读取响应是 BV_w，自由且彼此独立。

## 3. 实际检查项

静态阶段检查指令、类型、受支持接口、被初始化的所有读取、输入寄存器不得被写、
内存方向、cc、隐式 accumulator、tied operand、early-clobber 及别名假设。
所有未知语法拒绝；不能通过截取支持的指令前缀继续执行。

每个事件位置 i：

1. 两侧事件数相同，kind、mode、width 相同；不允许仅把失败 RMW 的 kind 改为 R。
2. 地址义务：`P ∧ (addrS_i ≠ addrT_i)` 不可满足。
3. 写值义务：普通写的值一致；RMW 的 `hasWriteS ↔ hasWriteT`，
   并在 hasWrite 时比较新值。没有写的一侧的填充值不作为语义字段。
4. 读值为耦合 u_j，必须检查它在各自状态中的传播、返回值、后续地址/事件/输出。
5. 事件存在条件在第一版恒真。遇到带条件的目标事件直接拒绝。
6. 出口检查所有公开标量输出以及可观察 flags；cc-clobbered 且未使用的 flags 可忽略。
7. 错误边界必须完全一致。第一版使用 Γ 的地址有效/无异常域，不能检查一般越界属性。

若扩展 DAG：在每个 R_i 下检查两侧下一边界 guards 的双向覆盖、重叠行为一致、
对应事件和后继 R_j；还须无无限 τ 路径。这里只给扩展义务，不宣称已实现 DAG checker。

伪代码：

```
Check(A,T,Γ):
  I := parse_and_validate_interface(A, Γ)
  source := independent_reference(A,I,Γ)
  target := typed_event_interpreter(T,I,Γ)
  reject unless static_shapes_match(source,target)
  for each reconstructed field-obligation φ:
      q := P ∧ ¬φ
      reject if solve(q) != UNSAT
      save q, solver/version, hash, timing
  accept EXACT with scope=restricted-open-block, Γ and hashes
```

目标无义务路径也不能绕过静态校验。源 hash、目标 hash、模型和义务由 checker 重建。
默认 P=true；调用方若要限制输入，必须在认证范围显式显示，不允许证书添加假设。
地址有效性属于模型域，不等于在机器所有地址上证明内存安全。

## 4. GNU 分配检查的保守子类

只接受 outputs 的 =/+、可选 &、r/q/a/m；inputs 的 r/q/a/m 或单一数字 tie。
q 只在固定 x86-64 且使用完整 32/64 位操作数时处理为所允许的 GPR 类；不支持 8 位/高字节。
多个输出寄存器不可互相共享；同一 fixed class 的冲突拒绝。
多指令中，非 & 输出在某仍需读取的无关输入（包括 m 的地址）前被写入则拒绝。
单条指令定义为先读取所有源值与有效地址，再同时更新输出；没有写后读 hazard。
纯输入寄存器不允许写；tied 输入在入口初始化对应输出；重复初始化必须一致或拒绝。
含未知硬编码寄存器、部分寄存器重叠、标志输出和寄存器 clobber 的第一版拒绝。

该规则牺牲覆盖率，但能解析证明分配无关性，避免枚举物理寄存器分配。
C 类型/有效地址/外部寄存器分配模型符合 GCC 契约仍是宿主条件。

## 5. 证书和可信计算基

证书含版本、源/IR/模型 hash、接口范围、切点对应、符号状态关系表达式、
完整 SMT-LIB obligations、各义务结果、求解器版本、结论和未建立的后端契约。
独立命令重读 A/T 并重建所有义务；不能只验证旧证书中的 UNSAT 文本。

TCB：受限 parser、接口校验、参考指令语义、Event IR 解释器、义务生成、位向量库、
SMT 求解器 UNSAT 可靠性、Python 运行时、文件绑定逻辑、Γ 的外部模型假设。
Lifter 不在 TCB。保存 SMT-LIB 是**可重放义务**，不是已核验 SAT 证明。
当前没有 LFSC/DRAT/LRAT 独立证明内核；不宣称 proof-carrying code 的小内核保证。

## 6. 复杂度和比较

n 个事件、s 个局部语句的 DAG 表达式表示下，生成 O(n+s) 个字段义务；
共享表达式避免纯文本指数展开。QF_BV 求解最坏复杂度不因局部化消失。
可逐义务复用上下文，但不能把已比较相等当未经证明的新前提。

TInA 的块端点验证不等于此开放读切点覆盖；但这不是对 TInA 的通用优越性结论。
Stellite 检查更一般的上下文变换，可增删事件；本算法用强结构限制换取 QF_BV。
Kater 解决关系代数公理/包含，本算法主要解决具体指令和 GNU 接口的实例验证。
Isla 的 ISA 事件生成可作更成熟参考；本 MVP 的手写小语义没有它的覆盖和机械化保证。
上述组合是否有足够新意尚未成立，必须以实际错误/收益与阶段 7 审阅决定。
